# Patient Vitals Report

A beginner Python script that calculates BMI and flags abnormal vital signs (fever, fast heart rate, high blood pressure) for a patient.

## What it does
- Stores a patient's data in variables
- Calculates BMI from weight and height
- Flags abnormal readings using comparison operators
- Prints a formatted vitals report
- Recalculates the fever flag after the temperature changes

## Concepts used
- Variables and data types (strings, integers, floats, booleans)
- Arithmetic operators and `round()`
- Comparison operators (`>`, `>=`)
- `print()` for output
- Reassigning variables
- Comments

## Example output
```
PATIENT VITALS REPORT
Name: Patient A
Age: 45
BMI: 25.7
Fever: True
Fast heart rate: True
High blood pressure: True
Temperature after treatment: 37.1
Fever now: False
```

## How to run
1. Download `patient_vitals.py`
2. Run it with Python 3: `python patient_vitals.py`
3. Or paste the code into any online Python editor

## Note
All patient data is fictional. This is a learning project and not a clinical tool.
